**Status:** Draft contribution package. No standards body has adopted these requirements.

This directory separates three things that must not be collapsed:

| Artifact | What it is | What it is not |
| --- | --- | --- |
| Internet-Draft source | A proposed set of execution-time authority requirements | An IETF position or an adopted standard |
| NEXUS crosswalk | A repository self-assessment against ETA-1 through ETA-20 | Independent conformance evidence |
| Review and briefing drafts | Target-specific contribution language | Permission to post or proof that contact details remain current |

## Start here

1. Read the [execution authority crosswalk](EXECUTION-AUTHORITY-CROSSWALK.md).
2. Review the [submission plan](SUBMISSION-PLAN.md) and its stop conditions.
3. Edit the canonical [XML source](ietf/draft-sullivan-wimse-execution-authority-00.xml).
4. Regenerate and compare the [plain-text rendering](ietf/draft-sullivan-wimse-execution-authority-00.txt).
5. Recheck every current draft revision and destination before using the [IETF list reviews](IETF-LIST-REVIEWS.md).

## Machine-readable evidence

[`execution-authority-crosswalk.json`](execution-authority-crosswalk.json) records one entry for each ETA requirement, its NEXUS status, evidence paths, and the remaining gap. Repository tests verify identifier completeness, status vocabulary, and local evidence paths.

## Safe interpretation

The XML source is the editable Internet-Draft source. The TXT file is a derived rendering retained for review. The attached reviews and standards-body briefs are dated working material. Draft revisions, group charters, addresses, membership rules, and submission windows can change. Verify them from the relevant body before posting.
