## Cases and expected evidence

V01/V02 cover contract over/under-grant; V03 delayed influence; V04 correct output with prohibited process; V05/V06 evidence display/export; V07 hostile telemetry and strategy memory; V08 audit-selection evasion; V09 repeated-run variation; V10 multi-product target drift. Each needs a legitimate pair, declared forbidden effects, independent observations and explicit unknown handling. Passing structural tests for this manifest does not establish that a runtime passes these cases.
